# CDTNet: Compositional Degradation Transfer Network for Test-Time All-in-One De-weathering Adaptation

This repository contains the official implementation of our WACV paper:

**CDTNet: Compositional Degradation Transfer Network for Test-Time All-in-One De-weathering Adaptation**

## Overview

All-in-one image de-weathering aims to restore clean images from diverse weather degradations, such as rain, haze, and snow. However, adapting restoration models to unseen target domains remains challenging, particularly when clean ground-truth images are unavailable.

CDTNet addresses this problem through compositional degradation transfer, enabling the transfer of degradation patterns from target-domain images to clean source-domain images for test-time adaptation.
